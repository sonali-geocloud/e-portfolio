FUNDAMENTALS OF GIS E-PORTFOLIO

Files
- index.html: complete single-page portfolio website.
- assets/images/: project screenshots for StoryMaps, Bavdhan school survey, and student portrait.
- README.txt: setup and publishing notes.

Preview locally
1. Extract the ZIP.
2. Open index.html in Chrome, Firefox, or Edge.

Before submitting
1. Confirm your professor accepts a custom HTML/GitHub Pages portfolio if the guideline requires Google Sites.
2. Check the syllabus topics and assignment details against your own course material.
3. Verify email, GitHub, LinkedIn, and StoryMap links.
4. Check your name, roll number, assignment titles, dates, and statistics.
5. Test the page on mobile and desktop.

Publish using GitHub Pages
1. Create/open a GitHub repository for this portfolio.
2. Upload index.html, the assets folder, and README.txt to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the deployment and use the URL shown in Settings > Pages.

Google Fonts require an internet connection. The website needs no build process.
